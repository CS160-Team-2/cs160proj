# OFS — On-Demand Food Delivery Service

CS 160 Software Engineering · Section 4 · Team 2 · Fall 2026

OFS is a website for a new local organic food retailer chain in downtown San Jose. Customers can browse organic groceries (fruits, vegetables and other items), add them to a virtual shopping cart, pay online, and have the order delivered to their home by a self-driving vehicle. Store employees and managers use a dashboard to query and update the inventory database and to monitor orders and deliveries.

## Frontend

React 18, Vite 5, Tailwind CSS v4 and React Router 7. Requires Node 20 or newer.

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```
